# 🍃 Leafy

Leafy es un bot de Discord enfocado en crear hábitos ecológicos y motivar a las personas a cuidar el planeta mediante retos, experiencia, niveles y logros.

---

# 🌎 Objetivo

El objetivo de Leafy es convertir pequeñas acciones ecológicas en algo divertido e interactivo dentro de Discord.

Los usuarios pueden:
- completar retos ecológicos,
- ganar XP,
- desbloquear logros,
- subir de nivel,
- y participar en una comunidad más consciente con el medio ambiente.

---

# ✨ Características

## 🌱 Sistema de experiencia (XP)
Los usuarios ganan experiencia al interactuar con el bot y completar retos.

---

## 🏆 Sistema de logros
Leafy desbloquea logros especiales según las acciones del usuario.

Ejemplos:
- 🌱 Primer Reto
- ♻️ Reciclador
- 💧 Ahorrador de Agua

---

## 📈 Sistema de niveles
Mientras más XP tengas, más niveles desbloqueas.

Ejemplo:
- Nivel 1 → Semilla
- Nivel 5 → Brote
- Nivel 10 → Planta
- Nivel 20 → Árbol

---

## 🌍 Retos ecológicos
Leafy genera retos ambientales para fomentar hábitos positivos.

Ejemplos:
- Reciclar
- Ahorrar agua
- Evitar plástico
- Caminar más

---

# ⚙️ Comandos

| Comando | Función |
|---|---|
| `!hola` | Saluda al usuario |
| `!reto` | Genera un reto ecológico y otorga XP |
| `!perfil` | Muestra el perfil del usuario, XP, nivel y logros |
| `!ayudar` | Muestra la lista de comandos disponibles |

# 🚀 Instalación

## 1. Clonar el repositorio

```bash
git clone TU_LINK_DEL_REPOSITORIO
```

---

## 2. Entrar al proyecto

```bash
cd leafy
```

---

## 3. Instalar dependencias

```bash
pip install discord.py
```

---

## 4. Configurar el token

Abre `main.py` y reemplaza:

```python
TOKEN = "TU_TOKEN_AQUI"
```

con el token de tu bot de Discord.

---

## 5. Ejecutar Leafy

```bash
python main.py
```
