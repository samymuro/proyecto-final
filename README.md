# 🍃 Leafy

Leafy es un bot de Discord enfocado en crear hábitos ecológicos y motivar a las personas a cuidar el planeta mediante retos, experiencia, niveles y logros.


# Objetivo

El objetivo de Leafy es convertir pequeñas acciones ecológicas en algo divertido e interactivo dentro de Discord.

Los usuarios pueden:
- completar retos ecológicos,
- ganar XP,
- desbloquear logros,
- subir de nivel mientras participa en algo interactivo
  

# Características

# Sistema de experiencia (XP)
Los usuarios ganan experiencia al interactuar con el bot y completar retos.



# Retos ecológicos
Leafy genera retos ambientales para fomentar hábitos positivos.

Ejemplos:
- Reciclar
- Ahorrar agua
- Evitar plástico
- Caminar más


# Comandos


| !hola:  Saluda al usuario |

| !reto: Genera un reto ecológico y otorga XP |

| !perfil: Muestra el perfil del usuario, XP, nivel y logros |

| !ayudar: Muestra la lista de comandos disponibles |

| !flip_coin: lanza una moneda |
